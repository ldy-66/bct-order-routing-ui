# BCT OMS 报单排序配置原型

用于展示报单顺序模板与客户配置交互的前端原型。

## 在线访问

[GitHub Pages](https://ldy-66.github.io/bct-order-routing-ui/)

## 当前功能

- 报单排序模板及模板配置维护
- 客户配置新增、编辑和批量删除
- 客户配置 Excel 批量导入与模板下载
- 导入校验失败后返回 UTF-8 TXT 错误详情
- 交易方向与开平标志独立配置

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
pnpm build:pages
```
